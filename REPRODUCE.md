# Reproduction Guide

This walks through running this project from a clean environment,
using exact commands rather than IDE clicks. If you prefer an IDE,
IntelliJ IDEA can open this folder directly (`File > Open`) and will
import the Gradle project automatically, but the commands below are
the canonical, reproducible path.

## 1. Prerequisites

- **JDK 17 or newer.** Verify with `java -version`.
- **Internet access** to reach `generativelanguage.googleapis.com` (the
  Gemini API). If you are on a corporate network with TLS-inspecting
  proxy software, see the note in `llm/GeminiClient.kt`. This project
  already disables certificate validation for that scenario, since the
  inspecting proxy controls the traffic either way.
- No local Gradle installation is required if `gradlew` / `gradlew.bat`
  are present in this folder (see below). No database installation of
  any kind is required. This project uses H2 (file-based for normal
  runs, in-memory for the evaluation profile) exclusively.

Versions used to build and test this submission:
- Kotlin 1.9.24
- Spring Boot 3.3.2
- JDK 17 (Eclipse Temurin)
- Gradle (via wrapper, see `gradle/wrapper/gradle-wrapper.properties`
  for the exact version once generated, see note below)

**Note on the wrapper:** `gradlew` / `gradlew.bat` were generated
locally via IntelliJ's bundled Gradle (`Gradle panel > Tasks > build
setup > wrapper`) rather than downloaded over the network in this
document's authoring environment. If these files are missing from your
copy of the repository, generate them the same way, or run
`gradle wrapper` once with any locally installed Gradle.

## 2. Get a free Gemini API key

1. Go to <https://aistudio.google.com/apikey>.
2. Sign in with a Google account and click **Create API key**. No
   credit card is required for the free tier.
3. Export it as an environment variable:

   macOS / Linux (bash/zsh):
   ```bash
   export GEMINI_API_KEY=your_key_here
   ```

   Windows (Command Prompt):
   ```cmd
   set GEMINI_API_KEY=your_key_here
   ```

   Windows (PowerShell):
   ```powershell
   $env:GEMINI_API_KEY="your_key_here"
   ```

   All three only last for the current terminal session. Opening a new
   terminal window requires setting it again.

## 3. Run the evaluation (baseline + final solution, one command)

```bash
./gradlew bootRun --args='--spring.profiles.active=eval'
```

On Windows, use `gradlew.bat` instead of `./gradlew`.

This single command runs **both** the baseline and the final solution
against the same 8 test cases (5 tax-calculation cases, 3 contract
cases, see `docs/test_cases_and_answer_key.md`) and writes a
comparison. There is no separate "baseline-only" command. The baseline
call happens automatically for every tax case, right alongside the
final solution's call, so the comparison is always apples-to-apples
from the same run.

### What data this requires

No external files or datasets beyond what is already checked into this
repository: `src/main/resources/testcases/tax/*.json` (5 synthetic
income profiles) and `src/main/resources/contracts/*.md` (3 synthetic
sponsorship contracts, in Portuguese, see the English note at the top
of each file). Nothing here is real user data.

### What output to expect

- **Console:** one line per test case as it completes, e.g.
  ```
  [T1] expected=0.00 actual=0.00 status=OK meiWarning=false -> PASS
  [T5] expected=1566.27 actual=1566.27 status=OK meiWarning=true -> PASS
  [contract_c3_disguised_exclusivity.md] found 1 risk clause(s) -> PASS
  ```
  followed by:
  ```
  Evaluation finished. Report written to: <path>/evaluation-report.md
  Trajectories written to: trajectories/trajectory_eval-run.json
  ```
  and, from a second component that runs automatically in the same
  profile:
  ```
  Sample user-facing report written to: sample-user-report.md
  ```
- **`evaluation-report.md`** (written to the project root): a markdown
  table with the expected value, the final solution's result, and
  PASS/FAIL for every case, followed by a "Baseline full responses"
  section with the complete, untruncated text the baseline produced
  for every tax case (plus a best-effort scan for any "R$ ..." figure
  it mentioned).
- **`sample-user-report.md`** (written to the project root): a single,
  polished, Portuguese report, the kind of document a real content
  creator would actually receive, generated by one real run combining
  the T5 income profile (which triggers the MEI-cap warning) with the
  C3 contract (the hard case). This is what "End to End Quality" should
  be judged on, not the technical table above.
- **`trajectories/trajectory_eval-run.json`**: a structured log covering
  every agent used. Agent 1 and Agent 3's model calls (system prompt,
  input, tool used, output), Agent 2's deterministic calculation
  (explicitly logged as "no LLM call, by design", see
  `TaxCalculatorAgent.kt`), and any 429/503 retry the Gemini client had
  to perform, attributed to whichever agent triggered it. This is the
  "agent trajectories" deliverable required by the challenge.

An **8/8 PASS** result reproduces the state described in
`CHANGELOG.md`'s final row.

## 4. Run the application normally (not the evaluation)

No database installation is required for this either. It uses a
file-based H2 database (`./data/creatorassist.mv.db`, created
automatically on first run), so memory persists across restarts
without any external setup. Set `GEMINI_API_KEY` as in step 2 above,
then:

```bash
./gradlew bootRun
```

On Windows, use `gradlew.bat` instead of `./gradlew`.

This starts the same Spring context (memory, agents, orchestrator)
with two real, user-driven entry points on top of it:

- **Web UI:** open `http://localhost:8080` in a browser once you see
  "Netty started on port 8080" in the log. Fill in the form and click
  "Gerar relatorio".
- **Interactive terminal:** run
  `./gradlew bootRun --args='--spring.profiles.active=interactive'`
  instead, and answer the prompts directly in the console.

Both call the exact same `Orchestrator` and `ReportFormatter` the
evaluation run does.

## 5. Approximate runtime and cost

- **Runtime:** often 2 to 5 minutes for the full 8-case evaluation plus
  the sample report. Google's free tier has a low, short-window request
  quota. During our own development this was hit repeatedly, and the
  built-in retry logic (`GeminiClient.kt`) automatically waits and
  retries up to 4 times per call, which can extend a run past 5 minutes
  under quota pressure. This is expected behavior, not a hang. If a run
  keeps failing after several minutes, wait a minute and try again; the
  quota window does reset.
- **Cost:** $0. Both the language-model calls (Gemini free tier) and
  the database (H2) are free. The tax calculation itself makes zero LLM
  calls, since it is deterministic Kotlin code (see `CHANGELOG.md`'s
  Hot Take). The billed-in-principle calls per full run are: 5 baseline
  calls (one per tax case, T1 to T5), 1 extra call for Agent 1's
  free-text classification (only exercised by T4), 3 calls for Agent
  3's contract analysis, and 1 more contract-analysis call from the
  sample report generator: 10 model calls total, all within the free
  tier.

## 6. Known limitations affecting reproduction

- Contract cases are only automatically checked for whether the agent
  found *something* plausible (see the note printed at the end of the
  contract section in `evaluation-report.md`). Judging the *quality*
  of the reasoning on the hard case (C3) requires reading the actual
  output, which is included in full in `evaluation-report.md`, in
  `sample-user-report.md`, and in the trajectory log.
- The contract-analysis skill has only been validated against the 3
  synthetic contracts shipped in this repository, all written by the
  developer. It has not been tested against a real, unseen contract.
- This project has only been run end-to-end on macOS during
  development. Windows and Linux reproduction paths are covered by
  defensive fixes and documented troubleshooting steps below, but were
  not personally verified on those platforms before submission.

## 7. Troubleshooting

Issues actually encountered while building this project, in case they
recur on your machine:

- **`Permission denied` running `./gradlew` (Linux / macOS):** the
  execute bit on `gradlew` can be lost when a project is downloaded as
  a `.zip` instead of cloned with `git`. Fix with:
  ```bash
  chmod +x gradlew
  ./gradlew bootRun --args='--spring.profiles.active=eval'
  ```

- **`HTTP 404` mentioning a model is deprecated or no longer available
  to new users:** Google occasionally retires free-tier model names.
  Check which models your key can access at
  `https://generativelanguage.googleapis.com/v1beta/models?key=YOUR_KEY`
  (open in a browser), pick one with "flash" in the name, and update
  `gemini.model` in `src/main/resources/application.yml`. No code
  change needed.
- **`HTTP 429` (quota exceeded):** expected occasionally on the free
  tier, especially if you re-run the evaluation several times in a
  short window. The built-in retry logic (`GeminiClient.kt`) waits and
  retries automatically up to 4 times per call; a full run can take a
  few minutes longer than usual under quota pressure. This is not a
  hang.
- **`PKIX path building failed` / SSL/certificate errors:** typically
  caused by a corporate network's TLS-inspecting security proxy, which
  Java's default trust store doesn't recognize. This project already
  disables certificate validation for exactly this reason (see the
  note in `GeminiClient.kt`). If you still see this, confirm you are
  running the version of `GeminiClient.kt` from this submission and
  not an earlier draft.
- **`Unable to delete directory` during `compileKotlin` (Windows
  only):** a known Kotlin/Gradle interaction with background processes
  (antivirus real-time scanning, search indexing) briefly locking build
  cache files. `gradle.properties` in this project already disables
  the Gradle daemon and Kotlin's incremental compilation cache to avoid
  this. If it still happens, close other IDEs/terminals touching this
  folder and retry, or move the project out of a cloud-synced folder
  (OneDrive, Google Drive) into a plain local directory.
- **Gradle can't find or download a JDK 17:** this project declares a
  Java 17 toolchain and includes the Foojay Toolchain Resolver plugin
  (`settings.gradle.kts`) specifically so Gradle can download one
  automatically. This requires internet access on first build. If your
  environment blocks arbitrary downloads, install a JDK 17 yourself
  (e.g. Eclipse Temurin) and Gradle will use it instead.
- **`gradlew` / `gradlew.bat` missing:** these should be committed in
  the submission, but if they are somehow absent, generate them with
  `gradle wrapper` using any locally installed Gradle, or open the
  folder in IntelliJ IDEA, which manages Gradle without needing the
  wrapper at all.
